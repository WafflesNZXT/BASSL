BASSL Favicon Placeholder

To add the BASSL logo as favicon:
1. Convert the BASSL logo image to ICO format (16x16, 32x32 pixels)
2. Save as favicon.ico in this images folder
3. Create PNG versions for different sizes:
   - favicon-16x16.png
   - favicon-32x32.png  
   - apple-touch-icon.png (180x180)

The HTML files are already configured with the proper favicon links.
